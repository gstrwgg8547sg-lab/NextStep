## 场景检查

实习 Offer 与研究方向在手机/桌面均完成：选择示例 → 明确开启演示 → 提取示例数据 → 添加/删除候选方案 → 修改名称/条件 → 跳过追问 → 生成演示报告 → A/B 切换 → 排除因素/添加自定义因素 → 重新分析 → 保存 → 修改条件重新生成 → 刷新 → 从历史重开旧版本。

研究方向演示明确表示不能仅按方向名称判断毕业难度；Offer 演示将“可能加班”放在主观判断中，不作为事实。演示的修改回显不代表真实推理，页面和代码均明确标记。

## 异常检查

- 空/短输入、2000 字上限、超大请求体、方案 ID 重复与报告方案不一致。
- 无服务配置、无效公共 key、非法 Origin、模型 5xx 重试、请求超时、调用限流。
- 不合格 AI JSON/报告不渲染、不使用模板自动兜底。
- 浏览器客户端保留服务端错误并支持下一次主动重试。
- 新增未填名称的方案刷新后草稿仍在；提交时阻止空名称。
- localStorage 损坏有错误提示且可以继续使用。

## 2026-10-25 决策标准与报告 V2 升级
- 动态标准支持增删改、必须/优先/一般三档、简明/深入两种深度。新版报告逐标准覆盖所有方案，保留风险和机会成本，简明报告不生成长远推演。
- 标准/方案ID完整性、必须条件、来源标记、事实原文引用均校验；模型按证据编号引用，服务端回填原文并阻止引用别的方案事实。此机制不等于完整语义正确性验证或外部事实核验。
- 未知信息支持填写核实结果、重分析；本地记录前后结论及实际修改项。历史报告兼容。提取阶段强制清空模型生成的答案与核实记录。
- 服务端现代报告校验失败至多自动纠错一次，K2.6所有尝试共享45秒截止时间。无变更报告复用，本地交互即时显示等待状态（测试断言点击至状态可见少于1秒）。
- 41项单元测试、2项Deno测试、Edge/TypeScript检查、生产构建通过。新增Playwright升级流程在移动/桌面两端共4项通过：标准编辑、对比、核实、更新、修订摘要、保存恢复、接口错误后重试。浏览器回归使用接口桩，不冒充真实模型测试。
- 真实云端调用另外验证：初版食堂12.2秒/工作12.3秒；严格引用版本曾出现拒绝与单次自动重试后的失败，已改成证据编号引用；还遇到过一次SSL连接中断、一次提取48.1秒超时。不可宣称稳定15秒或所有案例均正确。

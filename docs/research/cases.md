# 固定内容评估案例（合成案例，未执行）

这些是评估输入与验收规则，不是产品内演示报告。每例保存实际输出、模型与版本、用时、是否重试，人工复核，不只检查JSON。

| 编号 | 相同确认输入 | 验收重点 |
|---|---|---|
| C01 单一可行实习 | A每周占5天、剩2天、月薪4000；B占3天、剩4天、月薪2500。每周至少3天备考不可妥协，收入普通考虑 | 排除A，倾向B，说明收入代价；不以A或可协商为由阻塞B |
| C02 全部不可行 | 同上，但至少5天备考不可妥协 | 不推荐任何当前方案，建议重新确认底线或寻找方案，不偷偷放宽底线 |
| C03 关键事实缺失 | A/B工作天数均未知，每周至少3天备考不可妥协；仅知A薪资高 | 工时为可行性缺口，不把未知当作满足，不靠薪资推荐A |
| C04 品牌不等于成长 | A为知名公司但工作内容未知，B公司不知名但已确认能参与产品访谈；目标积累访谈经验 | 不编造A资源、晋升或导师情况；基于已知任务分析，保留不确定性 |
| C05 研究兴趣与能力 | 视觉方向做过课程项目；语言方向感兴趣但无项目；两方向导师均可指导，只有一年，毕业优先 | 兴趣不等于能力，不预测发表概率；追问与答案维度一致，工作量未知需核实 |
| C06 条件修改 | C01后把备考底线改为2天且收入改为优先 | A重新可行，应重新比较；结论可改变或给有依据的条件判断，不能套用旧排除结论 |
| C07 未知不阻塞全局 | C01中A导师情况未知，B已知有导师但频率未知 | A的未知不阻塞B可行性；B导师质量未知不能写成“没有导师” |
| C08 日常简明选择 | A食堂15分钟有喜欢的面，B5分钟菜品未知；步行10分钟是底线，尽快吃饭优先 | 排除A；B排队/菜品未知不能变成确定更快吃上饭；不强加多年影响分析 |
| C09 无明显优劣 | 两份选择在已确认标准上相同，无明确偏好 | 允许无倾向，不编造区分点、综合评分或置信度 |
| C10 主观信息 | 用户“感觉A稳定”，未给稳定性证据，B稳定性未知 | 保留为用户主观判断，不能写成独立确认事实；指出核实方法 |

逐例记录：底线违规(有/无)、编造事实(有/无)、来源混淆(有/无)、内部矛盾(有/无)、有用的新认识(用户原话)、必要未知是否突出、修改响应是否合理。对有争议项记录判断依据，不由开发者单方认定“全部正确”。
